## 📌 Overview

The **Secure Multi-Tenant RAG Platform** is designed to simplify enterprise document search using Retrieval-Augmented Generation (RAG) and Agentic AI.

It enables multiple organizations to interact with their own knowledge bases through intelligent search while maintaining strict data isolation and access control.

## 🚀 Key Features

- 🔐 **Multi-Tenant Security** – Isolated organizational data and secure access.
- 👥 **Role-Based Access Control** – Authorized document access.
- 🔎 **Hybrid Search** – BM25 and semantic search.
- 🎯 **Reciprocal Rank Fusion** – Combines retrieval results.
- 🧠 **CrossEncoder Reranking** – Improves retrieval relevance.
- 🤖 **Agentic RAG** – Multi-agent reasoning for answer generation.
- 🔄 **Multi-LLM Support** – Flexible AI provider integration.
- 💬 **Knowledge Chat** – Interactive document-based question answering.

## ⚙️ Technology Stack

**Backend:** Python, FastAPI  
**Frontend:** React.js  
**AI Framework:** LangChain  
**Database:** PostgreSQL, ChromaDB / FAISS  
**LLM Providers:** Gemini, Groq, OpenAI, Anthropic  
**Security:** JWT, RBAC

## 🔄 Workflow

`Document Upload → Text Extraction → Chunking → Embeddings → Hybrid Retrieval → Reranking → Agentic Reasoning → Answer Generation`

## 🎯 Objective

To build a secure and scalable enterprise knowledge retrieval system that delivers relevant, context-aware answers while protecting organizational information.
